## 🎨 공통 디자인 원칙

### 접근성
- 모든 버튼에 `aria-label` 또는 적절한 라벨
- 키보드 네비게이션 지원
- 시맨틱 HTML 사용
- 포커스 인디케이터 명확히

### 반응형
- 모바일: 1열
- 태블릿: 2열
- 데스크톱: 최대 너비 제한

### 다크 모드
- Tailwind `dark:` 클래스 사용
- 색상 대비 WCAG AA 준수

### 애니메이션
- `fade-in`, `slide-up` 효과
- Intersection Observer 활용
- `prefers-reduced-motion` 고려
