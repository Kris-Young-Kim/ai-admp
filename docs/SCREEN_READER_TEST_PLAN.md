# 스크린 리더 테스트 계획

> 작성일: 2025년 1월
> 목표: WCAG 2.1 AA 준수를 위한 스크린 리더 테스트 수행

---

## 📋 개요

스크린 리더 테스트는 시각 장애인 사용자가 웹사이트를 사용할 수 있는지 확인하는 중요한 접근성 검증 단계입니다. 이 문서는 프로젝트의 스크린 리더 테스트 계획과 가이드를 제공합니다.

---

## 🎯 테스트 목표

### 주요 목표

1. **모든 콘텐츠 접근 가능성 확인**
   - 모든 텍스트가 스크린 리더로 읽히는지 확인
   - 모든 버튼과 링크에 적절한 라벨이 있는지 확인

2. **키보드 네비게이션 확인**
   - Tab 키로 모든 인터랙티브 요소에 접근 가능한지 확인
   - 논리적인 포커스 순서 확인

3. **ARIA 속성 검증**
   - 모든 ARIA 속성이 올바르게 적용되었는지 확인
   - 스크린 리더가 올바른 정보를 제공하는지 확인

4. **폼 접근성 확인**
   - 모든 폼 필드에 라벨이 연결되어 있는지 확인
   - 에러 메시지가 접근 가능하게 제공되는지 확인

## 🛠️ 테스트 도구

### 권장 스크린 리더

#### 1. NVDA (Windows, 무료) - 권장
- **다운로드**: [NVDA 공식 사이트](https://www.nvaccess.org/)
- **설치**: 간단한 설치 프로그램
- **활성화**: Ctrl + Alt + N
- **장점**: 무료, 업데이트 빈번, 널리 사용됨

#### 2. JAWS (Windows, 유료)
- **다운로드**: [JAWS 공식 사이트](https://www.freedomscientific.com/products/software/jaws/)
- **활성화**: Ctrl + Alt + J
- **장점**: 가장 널리 사용되는 상용 스크린 리더

#### 3. VoiceOver (macOS/iOS, 내장)
- **macOS 활성화**: Cmd + F5
- **iOS 활성화**: 설정 → 접근성 → VoiceOver
- **장점**: macOS/iOS 기본 제공

#### 4. TalkBack (Android, 내장)
- **활성화**: 설정 → 접근성 → TalkBack
- **장점**: Android 기본 제공

### 브라우저 호환성

- **Chrome**: NVDA, JAWS, VoiceOver 지원
- **Firefox**: NVDA, JAWS 지원 (권장)
- **Safari**: VoiceOver 지원 (macOS)
- **Edge**: NVDA, JAWS 지원

## 📝 테스트 체크리스트

### 1. 기본 네비게이션

- [ ] **Skip Link**
  - Skip Link가 키보드 포커스 시 표시되는지 확인
  - Skip Link를 통해 메인 콘텐츠로 이동 가능한지 확인
  - 스크린 리더가 "주 콘텐츠로 건너뛰기 링크"라고 읽는지 확인

- [ ] **헤더/네비게이션**
  - 헤더가 "banner" 역할로 인식되는지 확인
  - 네비게이션 메뉴가 "navigation" 역할로 인식되는지 확인
  - 모든 링크에 명확한 목적이 읽히는지 확인

- [ ] **메인 콘텐츠**
  - 메인 콘텐츠가 "main" 역할로 인식되는지 확인
  - 섹션 제목이 올바르게 읽히는지 확인

### 2. 버튼 및 링크

- [ ] **텍스트 버튼**
  - 버튼 텍스트가 명확하게 읽히는지 확인
  - 버튼 상태(disabled, pressed)가 읽히는지 확인

- [ ] **아이콘 버튼**
  - 아이콘만 있는 버튼에 `aria-label`이 제공되는지 확인
  - 스크린 리더가 버튼의 목적을 명확히 읽는지 확인

- [ ] **링크**
  - 모든 링크에 명확한 목적이 읽히는지 확인
  - "자세히 보기" 같은 모호한 링크 텍스트가 없는지 확인

### 3. 폼 요소

- [ ] **입력 필드**
  - 모든 입력 필드에 라벨이 연결되어 있는지 확인
  - 라벨이 입력 필드와 함께 읽히는지 확인
  - 필수 필드가 표시되는지 확인

- [ ] **라디오 버튼 그룹**
  - 그룹 제목이 읽히는지 확인
  - 각 라디오 버튼 옵션이 읽히는지 확인
  - 선택된 옵션이 읽히는지 확인

- [ ] **체크박스 그룹**
  - 그룹 제목이 읽히는지 확인
  - 각 체크박스 옵션이 읽히는지 확인
  - 선택된 옵션이 읽히는지 확인

- [ ] **슬라이더**
  - 슬라이더 라벨이 읽히는지 확인
  - 현재 값이 읽히는지 확인
  - 최소/최대 값이 읽히는지 확인

- [ ] **에러 메시지**
  - 에러 메시지가 `role="alert"`로 표시되는지 확인
  - 에러 메시지가 자동으로 읽히는지 확인
  - 에러 필드가 `aria-invalid`로 표시되는지 확인

### 4. 동적 콘텐츠

- [ ] **ARIA Live Region**
  - 동적 콘텐츠 업데이트가 자동으로 읽히는지 확인
  - 로딩 상태가 읽히는지 확인
  - 매칭 결과가 읽히는지 확인

- [ ] **모달/다이얼로그**
  - 모달이 열릴 때 제목이 읽히는지 확인
  - 포커스가 모달 내부로 이동하는지 확인
  - ESC 키로 모달을 닫을 수 있는지 확인
  - 모달이 닫힐 때 포커스가 원래 위치로 돌아가는지 확인

### 5. 접근성 도구

- [ ] **접근성 도구 모음**
  - 접근성 도구 모음 버튼이 읽히는지 확인
  - 키보드 단축키(Alt + A)로 열 수 있는지 확인
  - 모든 설정 옵션이 읽히는지 확인

- [ ] **TTS (Text-to-Speech)**
  - TTS 버튼이 읽히는지 확인
  - TTS 컨트롤이 읽히는지 확인

- [ ] **키보드 스캔 모드**
  - 스캔 모드 버튼이 읽히는지 확인
  - 스캔 모드 활성화 상태가 읽히는지 확인

### 6. 섹션 컴포넌트

- [ ] **Hero 섹션**
  - 헤드라인이 읽히는지 확인
  - CTA 버튼이 읽히는지 확인
  - 신뢰 배지가 읽히는지 확인

- [ ] **문제 공감 섹션**
  - 섹션 제목이 읽히는지 확인
  - 각 문제 카드가 읽히는지 확인

- [ ] **AI 데모 섹션**
  - 폼 제목이 읽히는지 확인
  - 모든 폼 필드가 읽히는지 확인
  - 제출 버튼이 읽히는지 확인
  - 결과가 읽히는지 확인

- [ ] **신뢰 구축 섹션**
  - 수치 카드가 읽히는지 확인
  - 전문가 프로필이 읽히는지 확인

- [ ] **작동 방식 섹션**
  - 각 단계가 읽히는지 확인
  - 단계 번호가 읽히는지 확인

- [ ] **후기 섹션**
  - 후기 내용이 읽히는지 확인
  - 사용자 이름이 읽히는지 확인
  - 평점이 읽히는지 확인

- [ ] **요금제 섹션**
  - 각 요금제가 읽히는지 확인
  - 가격이 읽히는지 확인
  - 기능 목록이 읽히는지 확인

### 시나리오 1: 홈페이지 탐색
1. 페이지 로드

6. 결과가 읽히는지 확인

4. 변경 사항이 적용되는지 확인

## 🚀 자동화된 테스트

### Playwright + axe-core

```typescript
// tests/e2e/accessibility.spec.ts
import { test, expect } from '@playwright/test';
import { injectAxe, checkA11y } from 'axe-playwright';

test('스크린 리더 접근성 테스트', async ({ page }) => {
  await page.goto('/');
  await injectAxe(page);
  await checkA11y(page);
});
```

### Jest + @testing-library/jest-dom

```typescript
// __tests__/accessibility/aria.test.tsx
import { render, screen } from '@testing-library/react';
import { Button } from '@/components/ui/button';

test('버튼에 aria-label이 제공되는지 확인', () => {
  render(<Button aria-label="제출하기">제출</Button>);
  const button = screen.getByRole('button', { name: /제출하기/i });
  expect(button).toBeInTheDocument();
});
```
